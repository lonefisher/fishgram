# 搜索实测与证据记录

本清单执行原 `restricted-global-search` 的八项验收，不修改其规格、性能目标或 Comet 状态。当前 helper、同一生产核心的模拟 transport/clock 测试与完整产品 UI 是不同证据层；逐项由独立 Verifier 判断，未执行、失败或跳过不计通过。

## 准备

记录候选父提交、源码提交、程序 SHA256、显示版本、Windows 版本及对应云端 run。只使用同一个固定候选，测试期间不重新编译或替换程序。真实账号使用独立工作目录，正常退出后的数据快照与异常退出保全副本分开记录；不把真实账户数据映射进 Sandbox。

选择匿名样本编号，私有记录保存对应消息和查询。至少准备原生全局搜索遗漏而会话内搜索可找到的受限消息、相应媒体及一个不属于当前范围的对照会话。缺少任何样本时记录缺项，不用无关命中替代。截图、查询词、消息正文、账号与频道名称留在私有区。

## 原八项操作与判断

| 项目 | 实际检查 | 通过所需证据 |
| --- | --- | --- |
| A1 主搜索及媒体 | 先关闭补查并查询样本，再开启补查；主搜索和相应媒体搜索均命中，点击打开正确原消息；再次关闭恢复原生路径 | 同一候选和样本的开启/关闭对照及原消息定位；核心测试不替代点击验证 |
| A2 范围 | 分别检查 Main、Archive、无 folder、会话类型、日期、媒体过滤和 Community；折叠成员、未知 restricted 完整解析及不在范围内的缓存 peer 单独核对 | 每种范围的正反样本；缺 Community 或未知状态样本需明确保留未验，并结合模拟 RPC 证据 |
| A3 排序与分页 | 连续滚动多页，检查重复及时间边界；模拟 RPC 对每批和最终序列与静态并集按 MessagePosition 降序及 FullMsgId 去重的参照比较 | 真实滚动结论加同核心的跨页同时间、单源多页、重复、过滤后空页和每 peer 唯一策略测试；目视几条结果不能证明完整排序 |
| A4 生命周期 | 快速输入、更换范围/过滤器、切换账号和开关；旧查询结果不能污染新查询；空文本媒体过滤有效 | 真实操作记录及模拟迟到 RPC/缓存/取消证据；350ms 从最后输入计，不能与原生延迟串联 |
| A5 失败与重试 | 使用隔离模拟 transport 覆盖 FloodWait、网络失败、10秒超时、准备未完整及异常游标；真实 UI 验证不完整提示和整轮重试 | 冷却内不重试、旧结果保留至新首屏替换、旧页无迟到插入；不故意向真实服务大量发送请求制造 FloodWait |
| A6 设置与计数 | 核对每账号默认开启；两账号分别保存不同开关，正常退出并重启后读回；加载时显示已加载数量 | 两账号隔离与重启持久化；精确总数仅在全部来源成功且分页耗尽显示，Partial 耗尽仍保持不完整提示 |
| A7 调度与性能 | 列表已加载、正常网络下重复测首屏并记录规模；并发6上限及无候选截断由生产核心和调度证据核对 | 每次真实耗时、来源数量、是否 Partial 与网络条件；约2秒目标超出必须如实记录，不悄改目标或减少范围 |
| A8 构建与交付 | 核对原固定基线/递归子模块、未修改基线和改版 x64 Release、独立便携数据、ZIP/校验/源码及实际报告 | 原搜索交付保持官方更新关闭；FishGram 自有更新另由更新 change 验收。历史 r7、测试身份云端和正式产品候选分开，不自动沿用结论 |

## 耗时与脱敏记录

生产日志 `RestrictedSearch: prepared` 记录来源数、Partial 和准备耗时；`RestrictedSearch: page` 记录已加载数、has_more、错误类型和从该轮 Coordinator start 开始的耗时。第一条 page 可作为协调器首屏耗时，不能直接当成从最后按键到 UI 绘制完成的耗时；后者另行实测。多页日志不能误当成多轮首屏样本。

公开报告只保留样本编号、版本/提交/哈希、范围类型、通过/失败/未执行、数量、耗时和已知限制。公开前逐项审查，不上传完整客户端日志；即使搜索统计行不含正文，日志其余部分也可能包含私人信息。

真实客户端未就绪时，准备样本和执行步骤即可，不填造成功。验收状态只能由 Comet Runtime 更新，本清单本身不是验收报告或发行批准。
