# 首版 Beta 发行

## 2026-10-31 Scoop 优先发行决定

用户明确要求跳过剩余测试先发布，目标是尽快通过 Scoop 安装使用，发现问题后再修复。首版使用已成功构建的 `7.3.3-r11` 产品候选，发布为 GitHub prerelease，并提供 `fishgram-beta` 清单。

本次发行公开列出尚未完成的完整搜索范围覆盖、网络恢复后的整轮重试、更新安装及恢复矩阵，以及下文的性能和原生遗漏对照样本。原验收记录保留实际结论，后续按用户反馈继续修复。

程序 ZIP、对应源码、构建记录和 SHA256 同时发布。Scoop 安装写入 `externalupdater.d`，持久化 `FishGramData`，更新由 `scoop update fishgram-beta` 管理；便携用户手动下载更新。客户端自动更新通道以后再推广，沿用签名和完整恢复验收流程。本次可直接发布这些下载附件，无需等待原完整签名发布工作流。

## 原验收范围

2026-10-19 用户明确允许首版先以 Beta 发布，并公开以下搜索限制：

- 大范围受限会话搜索尚未达到原先约 2 秒首屏的性能目标。既有约 99 个来源的实测需约 35–37 秒；性能优化继续保留在原搜索 change。
- 暂无“原生全局搜索遗漏、会话内搜索可找到”的明确消息和媒体对照样本，此项保持待验。

这两项作为 Beta 已知限制，不能改记为通过。其余搜索验收继续执行。签名、更新安全、安装、恢复、本机同一云端候选及公开下载核验仍须完成。

## 渠道

GitHub Release 必须标为 prerelease，更新索引只推广 `beta.json`。稳定索引不推广这个 Beta，普通稳定版用户不会自动收到。用户主动下载或选择 Beta 后才使用。

当前Qt6配方直接构建Beta渠道，程序、Updater和签名包使用同一渠道。客户端也支持稳定签名包进入Beta索引；早期候选39128598025保留为Qt5历史实测。正式发行使用完成验收的同一新版云端候选，签名渠道保持其实际值。Beta转稳定版时分配新修订号。

Release 说明和便携 ZIP README 都需写明 Beta 及上述两项限制，下载入口优先指向便携 ZIP，源码单独提供。公开 QA 使用明确的 Beta 验收类型，列出这两项暂缓；其他检查仍须通过。该类型不能进入稳定索引。

Scoop 首版使用显式的 `fishgram-beta` 清单，指向已公开的 Beta Release，持久化 `FishGramData`，由 Scoop 管理更新；正式稳定版另外维护 `fishgram`。不使用 GitHub `/releases/latest` 检查 Beta，因为该入口排除 prerelease。
