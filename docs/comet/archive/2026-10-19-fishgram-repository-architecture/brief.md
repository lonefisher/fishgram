# 非目标
本 change 不发布客户端二进制，不替代搜索功能的全项验收，不创建付费 runner，不改写官方历史或推送本机私有分支，不手改 Runtime 状态。GitHub App、发布密钥和远端发行保护由后续专门 change 实施。

# 验收示例
- A1：迁移前已验证 Git bundle、工作树 patch、暂存 patch、所有新增源码与实际五组测试的哈希备份；运行数据快照仅在目标实例正常退出后创建，并验证文件完整性。
- A2：公开源码 fork 的 parent 是 telegramdesktop/tdesktop；custom/main 以固定官方提交与审查的定制源码为基础；所有实际测试被跟踪，AGENTS.md 与对应官方版本完全一致，私有本机文档提交不在公开分支祖先中。
- A3：公开父仓库 main 的 .gitmodules URL 指向源码 fork，tdesktop gitlink 模式为160000且提交在远端可取；全新递归克隆可取得预期源码与子模块，官方历史与当前功能文件保留。
- A4：定制指令仅在父 AGENTS.md，唯一更新维护正文在父 docs/UPDATING.md，源码 README 明确 FishGram 非官方身份并指向父仓库；维护指南覆盖修复、升级、回退、换机器和后续发行门槛。
- A5：两个公开仓库与待发布历史不含凭据、账户数据、原始日志/截图、真实查询词/私人频道名、机器私有配置；忽略规则覆盖运行时、缓存和暂存包。公开验证记录使用匿名结论与提交、哈希。
- A6：构建、测试、准备、打包工具读取固定配方并定位工具链，移除用户名、VS绝对路径、官方版本硬编码；依赖缺失、身份缺失、版本不一致和既有包路径均明确失败，不输出API参数。
- A7：干净打包暂存区与运行目录不同；包白名单检查拒绝账号数据、私有配置、日志及未批准文件；生成源码/子模块/工具链/产物哈希清单，父许可与依赖许可保留。
- A8：现有 restricted-global-search 的状态与八项验收未被重置或伪造通过，r7程序和账号数据未被替换；新增架构、云端发行和自动更新拥有独立 Comet 工作；只有完整发行门槛通过才允许公开安装包。

# 约束与不变量
用户使用电脑时保持前台和真实鼠标不受干扰。GUI使用Cua Driver后台操作并读回。源API hash、私钥和账户数据不进入聊天、Git或公开日志。原数据恢复必须保留备份。两层提交先推源码再推父指针。不得强制 reset、删除或重克隆原工作区。

# 决策
用户已在本聊天批准完整方案并明确要求实施，沿用该确认，不再次请求相同范围的许可。父仓库原先未初始化；先备份并建立最小 Git 入口；Comet要求与 active 搜索 change 隔离，架构使用独立 worktree。本工作为一个普通 change，不使用 Supervisor，多仓库步骤由同一执行者依次实施。
