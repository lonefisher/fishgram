# 目标
落实已批准FishGram方案 §3、§4恢复及密钥维护、§5④：仅FishGram信任源的v2签名自动更新，自动下载、下次用户重启安装，失败恢复与维护流程。现有搜索和云端候选门槛保留。

# 范围
复用现有v2签名/Packer/WindowsUpdater；完整“官方＋修订”64位版本贯穿客户端、Packer、ready标记、Updater，JSON十进制字符串。Releases附件、Pages稳定/Beta索引与根签名清单；去除官方HTTP/MTP发现和RSA回退。根钥离线加密备份，发行钥受保护环境一年有效、45天前提醒；清单递增、续期、吊销、拒绝回退，根损坏手动重装。

默认稳定自动检查下载、可关；Beta主动选择。完成提示下次重启，不自动退出抢窗口。按workdir单实例，同安装目录单事务。校验签名/目标/渠道/版本/大小/哈希/解包路径，拒绝路径穿越和账户载荷。空间/权限/退出检查，完整程序备份、事务恢复、最近三程序版；跨官方版本正常退出数据快照最近两份，新版迁移后恢复数据需用户明确选择。断网/中断/坏签名继续当前客户端、可理解错误。问题版停止推广、记录并发布递增修复，在线不降级，独立手动恢复。

# 非目标
不采购Authenticode、不重编译已验收候选、不加入遥测、不自动发布、不放宽搜索性能验收；根密钥丢失不承诺安全在线更换。

- A1：FishGram发现源与v2-only实际有效，官方发现/RSA包不可作为回退，平台/渠道/完整版本绑定。
- A2：同基线r8→r9、跨基线、Beta主动选择/转稳定新修订、旧版本及JSON大整数均正确处理，客户端/Packer/ready/Updater一致。
- A3：根签名清单验证、单调版本、年度发行键过期/续期/吊销/回退拒绝、45天提醒、根离线加密备份及手动重装文档通过。
- A4：自动下载可禁用；完成仅提示下次重启，不退出/抢窗口，多个workdir和同安装单事务正确，启动器不默认-many。
- A5：损坏/错误签名/官方/旧包、大小/哈希/目标/渠道错误、路径穿越及账户目录载荷被实际拒绝且当前客户端可继续。
- A6：中断/断网/服务不可达重试和理解性错误；空间不足、权限失败、进程未退、文件占用均不破坏现有程序。
- A7：事务备份、替换失败/中断恢复、最近三程序版本、跨基线退出后两份数据快照、显式数据恢复和独立手动回退实测。
- A8：干净Windows11首次运行，实际云端同一候选签名/更新安装/恢复链路通过；搜索与云端门槛全过才首发，未通过不发布索引。
